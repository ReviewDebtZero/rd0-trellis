# Agent guide

## Code style
- Never use `console.log` in product code; use the `logger` from `src/lib/log`.
- Do not use `any`. Model the type or use `unknown`.
- Prefer named exports. Avoid default exports.
- Use `useSyncedState` instead of `useEffect` for derived state.
- Never import from `src/main` in `src/renderer`.
- Don't add the `lodash` package; use the standard library.
- Do not leave commented-out code.
- Never silence lint or type errors with `eslint-disable` or `@ts-ignore` without a reason.
- Don't edit `src/generated/`; it is regenerated by `make codegen`.
- Keep changes minimal and don't touch unrelated files.

## Process
- Run `npm test` before you open a PR.
- Write clear commit messages.
- Make sure new features are easy to understand and match the existing architecture.
